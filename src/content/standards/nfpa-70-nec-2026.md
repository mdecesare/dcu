The current edition of the NEC is 2026. NFPA describes the code as "enforced in all 50 states," but each
state and many localities adopt editions on their own schedule, so the edition that applies to a project
can be older.

NFPA is part-way through reorganizing the code: articles for installations over 1000 volts ac and 1500
volts dc arrived in the 2023 edition, more changes came in 2026, and completion is targeted for the 2029
edition. For 2029, public input closed on 9 April 2026 and the First Draft Report is due on 10 June 2027.
