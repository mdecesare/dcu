The current edition of the NEC is 2026. NFPA describes the code as "enforced in all 50 states," but each
state and many localities adopt editions on their own schedule, so the edition that applies to a project
can be older.

**Standards process:** NFPA is reorganizing the code over several editions, with completion targeted for
2029; the 2029 First Draft Report is due 10 June 2027.
